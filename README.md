# scratch-arcade-game
Game developed with Scratch featuring interactive gameplay and animations.

A simple arcade game developed in Scratch during my first year of university.

The player controls a dog using the arrow keys and tries to collect as much food as possible during a 10-second round. Each collected food item increases the player's score by 10 points.

## Features

- 10-second game rounds
- Player movement using the arrow keys
- Food collection and collision detection
- Score tracking
- Restart functionality
- Leaderboard that stores scores during the game session
- Leaderboard sorting in descending order
- Additional interaction using the Space key

## How to Play

1. Start the game using the green flag.
2. Use the arrow keys to control the dog.
3. Collect as much food as possible before the timer reaches zero.
4. After the round ends, use the Restart button to start another round.
5. Try to achieve a higher score and improve your position on the leaderboard.

Pressing the Space key makes the dog bark and move to a random position.

## Concepts Used

- Event-driven programming
- Variables and lists
- Loops and conditional statements
- Collision detection
- Cloning
- Score and timer management
- Sorting algorithm

## Running the Project

The `.sb3` file can be opened using Scratch 3.

1. Open Scratch.
2. Go to **File → Load from your computer**.
3. Select `arcade_game_final_project.sb3`.
4. Press the green flag to start the game.
